# Just One Last Patrol — playtest checklist

**Session:** Thursday 26 November 2026
**Mission:** Just One Last Patrol, Kunar (`Missions/JOLP.conf`)
**Build under test:** the current mod. Dedicated server, or a listen host plus at least one joining client.

This is a pass/fail sheet for one sitting. Write the result on the line. A blank box is an untested item, not a pass.

---

## How to run the session

Suggested length: about two hours. If people arrive late, do Block A, then Block C, then whatever is left of Block B.

| Block | Time | Who | Goal |
|-------|------|-----|------|
| A. Smoke | 20 min | Everyone, together | The session starts, you can move, shoot, and drive |
| B. Systems | 50 min | Split the list | One pair owns each section below |
| C. Save and reload | 30 min | Host drives, everyone watches | One deliberate save, one full restart, one compare |
| D. Join in progress | 15 min | One player drops and rejoins | A late joiner sees the world the server already has |
| E. Performance | 15 min, plus notes all session | Whoever is on the host | Hitches, frame rate, AI count |

**Roles**

- **Host.** Starts the server, is an admin, writes down numbers before the save.
- **Client.** Joins after the host is already in game. This person owns Block D.
- **Note taker.** One shared doc or this file. Every fail gets a bug line at the bottom.

**What to write when something fails**

```
ID:
Who saw it (host / client / both):
Where (town name, FOB, grid if you have it):
What you did:
What you expected:
What happened:
Did a restart fix it:
```

Also grab the server log line if one appears. Useful tags: `[JOLP]`, `SCRIPT (E)`.

**Controls testers will need**

| Action | Keyboard | Gamepad |
|--------|----------|---------|
| Self menu (call civilians, admin) | Ctrl + T | View + D-pad up |
| Apply a saved loadout | F | Y |
| Delete a saved loadout | X | X |

**Session rules**

- Start from a **new game**, not an old continue, unless Block C says otherwise.
- One person changes the world at a time during Block C. Two people building during the save makes the compare useless.
- Do not use Game Master to spawn extra AI while testing spawn, despawn, or performance. GM is its own row.
- Admin **Change time** does not pay supply income for the hours it skips, and it must not plant a fresh batch of IEDs. That is intended.

## Not in this build

Do not file these as bugs. The public readme still describes older Hearts and Minds ideas. The code does not have them.

- Side missions, leaflets, civilian taxi, towing
- A separate money or recruit system. Supplies are the currency
- Animal spawning
- Player skills

Reputation that **does** exist: killing milician, defusing an IED, a player death, damage to buildings, and morning pressure from a milician garrison. Ask a civilian "What's the current reputation in the settlement?" to read it. Starting score is 0, which is the **Low** band.

## A. Smoke (everyone)

Do these in order before splitting up. Stop the session if the first three fail.

- [ ] **A1. Server comes up.** Mission loads on Kunar. No infinite loading screen. Players can spawn at the start.
- [ ] **A2. Spawn.** You have a weapon and can move, aim, and fire. No invisible body, no missing hands.
- [ ] **A3. FOB Thunderbolt exists.** The starter HQ is on the map. The faction map shows a marker for it.
- [ ] **A4. Supplies are seeded.** Thunderbolt's supply stock reads about **1000**. Write the exact number: ______
- [ ] **A5. Towns exist.** Walk or drive toward a named settlement (Asadabad or another city name, not `Town_0`). Milician appear as you get close. Host log should contain `Map-descriptor seed` and real settlement names.
- [ ] **A6. Hideouts exist.** Host log: `Hideout selection: promoted N / wanted 5`. On a Workbench or listen host, each living hideout has a map marker. On a dedicated server, markers are off on purpose.
- [ ] **A7. Civilians exist.** A village or town has people on foot and, on a road, a civilian car. They are not soldiers.
- [ ] **A8. Respawn.** Die once. You come back at a player spawn. Gear is whatever the respawn loadout is, not a crash.
- [ ] **A9. Second client.** A second player joins while the host is already at Thunderbolt. They spawn, see the host, and see the FOB marker.

## B. Systems

Split these. Each box is one check. Expected result is the pass condition.

### B1. Milician garrisons

- [ ] **B1.1 Wake a town.** Approach a town that was quiet. Within its area, groups appear (sentry, patrol, or a checkpoint on a road). They shoot at you. They are not friendly.
- [ ] **B1.2 Leave the town.** Drive well past the edge and wait. The groups despawn. The game does not keep every town's soldiers in the world.
- [ ] **B1.3 Come back.** The town wakes again. You do not get a second full garrison stacked on survivors that never left.
- [ ] **B1.4 Checkpoint.** If a checkpoint spawned, it sits on a road with some fortification, not in a field or inside a building.
- [ ] **B1.5 Patrol returns.** If you watch a patrol without wiping it, it eventually heads back instead of wandering the whole map forever.
- [ ] **B1.6 City sniper.** In a town or a city, look on flat roofs after the garrison wakes. A sniper is optional (about a 15% roll, once). If one appears, he stays on the roof. If the roll fails, nobody is standing in the street as a "sniper". Villages do not roll one.
- [ ] **B1.7 Kill and store.** Kill a few men, then leave until the pack despawns. Come back. The town should be weaker, not reset to full, until a hideout reinforces it.
- [ ] **B1.8 QRF.** Start a fight in a town and hold it. A reinforcement vehicle or squad comes toward the contact from outside, rather than popping in on top of you. After the fight, note whether they hunt your last position or sit in the town.

### B2. Hideouts

- [ ] **B2.1 Five of them.** Count living hideouts (map markers in a non-dedicated session, or the host log). Expected: 5, unless the mission slider was changed.
- [ ] **B2.2 They are villages.** Hideouts are village-sized places, not the city you just fought in.
- [ ] **B2.3 HQ prop.** Each one has the hideout HQ crate. Destroying it is the objective, not killing every soldier.
- [ ] **B2.4 Destroy one.** Destroy a hideout HQ. Its soldiers despawn. Its marker goes away. It does not come back when you leave and return.
- [ ] **B2.5 FOB does not erase a hideout.** A player FOB near a hideout does not delete that hideout. Towns and OPs are the ones a FOB shuts down.

Hideout reinforcement is every **30 minutes**. Skip it unless the session runs long. If you do wait: the hideout gains men, then may send a squad to a weak nearby town.

### B3. Player FOB and suppression

- [ ] **B3.1 Thunderbolt suppresses.** A town whose centre sits inside Thunderbolt's radius does not spawn milician. A town clearly outside it does.
- [ ] **B3.2 Unfinished HQ does nothing.** In the build menu, place a Headquarters and leave it as an outline. Nearby towns still spawn milician.
- [ ] **B3.3 Finished HQ does.** Complete that Headquarters (supplies spent, composition finished). It gets a faction map marker with the FOB name. Towns whose centre is inside it go quiet, including any groups already there on the next tick.
- [ ] **B3.4 Remove it.** Disassemble that FOB. Those towns can spawn milician again.

### B4. Building and supplies

Thunderbolt starts at about 1000. Passive income is **150 supplies every 15 in-game minutes**, on a finished supply source. The hold action **Produce supplies** adds **10** per completed bar (about a 5 second hold).

- [ ] **B4.1 Build mode.** At the Thunderbolt command-post table, **Show build preview** opens the build menu. You can see services, fortifications, and headquarters. Cards are not empty.
- [ ] **B4.2 Place and pay.** Place a cheap fortification (sandbags). The supply stock goes down by the card's cost. The piece finishes in the world, not as a stuck outline.
- [ ] **B4.3 Refund.** Disassemble that piece. You get the supplies back (default is a full refund).
- [ ] **B4.4 Cannot afford.** Try something that costs more than the stock. Placement is refused. The stock does not go negative.
- [ ] **B4.5 Two builders.** Host and client open the build menu at the same time and place one piece each. Both pieces exist. The stock dropped by both costs, once each.
- [ ] **B4.6 Produce supplies.** Hold **Produce supplies** on a finished Supply Production building. One completed bar adds 10, on the host and on a client. The bar does not complete twice for one hold.
- [ ] **B4.7 Passive income.** Note the stock and the in-game clock. Wait 15 in-game minutes without using admin time skip. The stock rises by 150 (or a multiple of 150 if you waited longer). Write before / after: ______ / ______
- [ ] **B4.8 Admin time skip does not pay.** Note the stock. Admin menu, **Change time**, **+1 hour**. The clock jumps. The stock does **not** jump by 4 × 150.

### B5. Vehicles

Light depot lists the small vehicles (MRZR, M1025, JLTV). Heavy depot lists Strykers, M1083s, LAV-25. A helipad lists the large slot. Prices live on the request list.

- [ ] **B5.1 Light depot.** Request the cheapest vehicle (MRZR, 100 supplies). It spawns at the pad, facing a sensible direction, and the stock drops by 100.
- [ ] **B5.2 Heavy depot.** The light list does not show a Stryker. The heavy list does. Request one only if the stock can pay it.
- [ ] **B5.3 Drive it.** Enter as driver, as passenger, and in a turret if it has one. Host and client can both ride. It does not explode on spawn or sink into the ground.
- [ ] **B5.4 Refund once.** Return or delete it the way the depot allows. Supplies come back **once**. A second refund does not happen because a child part also asked.
- [ ] **B5.5 Command truck.** Request the **M1083 Command Post** (1000 supplies) from the heavy depot. Get out. From outside the empty truck, **Establish FOB** opens a name dialog.
- [ ] **B5.6 Deploy.** Confirm a name. The truck is gone. A new FOB exists with that name and a map marker. The 1000 is **not** refunded.
- [ ] **B5.7 Cancel.** On a second truck, open the dialog and back out. The truck stays. Nothing is deployed.

### B6. Arsenal and loadouts

Use the weapons or equipment arsenal box. Actions: **Save loadout**, **Loadouts**.

- [ ] **B6.1 Change kit.** Take a different weapon and vest from the arsenal. Supplies drop by that gear's cost.
- [ ] **B6.2 Save.** **Save loadout**, give it a name. The dialog closes cleanly on keyboard and on gamepad.
- [ ] **B6.3 List.** **Loadouts** shows that name, the price difference against what you are wearing, and the arsenal's supply count.
- [ ] **B6.4 Apply.** Strip or change your kit, then apply the saved one with F / Y. You wear the saved kit. Supplies change by the difference only, not by the full price again.
- [ ] **B6.5 Too poor.** Spend the stock down, then try to apply a more expensive kit. The dialog says there are not enough supplies. Your current kit stays on.
- [ ] **B6.6 Delete.** Delete the kit with X. It leaves the list. Applying is no longer possible.
- [ ] **B6.7 Per player.** The other player does not see your names. They can save their own. Rejoin and your list is still yours (confirm again in Block C).

### B7. Civilians

Call range is **10 m** (Ctrl+T, or the self menu **Come closer**). Talk range is **4 m**. Choices: reputation, enemy hint, hide and take cover.

- [ ] **B7.1 Population.** A village has people. A town has more. A city has the most. They wear civilian clothes, not one identical outfit.
- [ ] **B7.2 Traffic.** A civilian car drives between towns on the road. It is not a milician truck. It despawns when you leave the area.
- [ ] **B7.3 Call.** Stand near civilians, Ctrl+T or **Come closer**. People within 10 m walk to you and stay long enough to talk. People farther away do not all sprint across the town.
- [ ] **B7.4 Talk.** Speak to one. All three choices return a sentence. **Reputation** names the settlement and a band (Very low / Low / Moderate / High / Very high), not a crash or "They won't talk" while you are beside them.
- [ ] **B7.5 Too far.** Step back past a few metres and ask again. You are told they are too far. The menu does not apply the order anyway.
- [ ] **B7.6 Take cover.** Choose **Hide & stay cover**. Nearby civilians move into a building and stay there.
- [ ] **B7.7 Intel.** At Low reputation (the start), **Any hint about enemies?** may be a lie: a direction that is not a real hideout. Raise reputation (kill milician, defuse an IED) and ask again in a better town. A true hint points at a living hideout, with some offset, and the same civilian does not repeat a brand-new secret every sentence.
- [ ] **B7.8 Do not farm despawn.** Milician who despawn because you left are not "kills". Reputation should not jump because a town unloaded.
- [ ] **B7.9 Player death.** Die inside a town, respawn, and ask the reputation again. That place should be a bit worse (about −1).
- [ ] **B7.10 FOB quiets the town.** A town suppressed by your FOB does not keep spawning civilian cars through the base.

### B8. Low-reputation threats

These are easiest at the start, while reputation is Low. Very low is below −4.

- [ ] **B8.1 Partisans.** Kill a civilian in a settlement, or fight there long enough for the town to turn. Some of the remaining people become armed (AK) and hostile. They are not the whole town at Low (the cap is well under half).
- [ ] **B8.2 Suicide vest.** At Low or Very low, a civilian may close to a few metres and detonate. It kills people in range. It does not happen in a high-reputation town.
- [ ] **B8.3 Mortar.** Start a firefight in a Low town. An off-map or nearby mortar team may fire: a few ranging shots, then a salvo, then the tube goes away. Shells land near the last known players, not in a random empty field every time. If no tube appears, say so — it is a roll when the town first enters combat, not a guarantee.

### B9. IEDs

Charges are planted on the road shoulder near villages, towns, cities, hideouts, and OPs. A pile of cardboard or tyres with nothing in it is a decoy.

- [ ] **B9.1 Find one.** Drive the roads near a town at Low reputation. You find either a real charge (clock, detonator, or sensor) or only rubbish. Rubbish alone must not explode.
- [ ] **B9.2 Spacing.** Two live charges are not on top of each other. The action to cut the wire is reachable. You are not forced to stand on the bomb.
- [ ] **B9.3 Defuse.** Cut the safe wire. The charge stays as a dead object. Driving over it later does not explode. Reputation in the nearest town ticks up a little (about +0.25). Ask a civilian to confirm.
- [ ] **B9.4 Detonate.** On a different charge, trigger it (drive over a sensor, or cut the wrong wire). It explodes. Civilians in the blast can die. You can die. A second explosion does not fire from the same spot.
- [ ] **B9.5 FOB clears them.** After a FOB covers a place, that place's charges are gone, including any charge sitting inside the FOB even if it "belonged" to somewhere else.
- [ ] **B9.6 Daily plant.** New charges are a morning event around **08:00**, not every few minutes. If you are already past 08:00 when you test, do not expect a new wave until the next morning. Admin time skip onto or past 08:00 must **not** plant a wave by itself.

### B10. Admin and Game Master

Self menu, **Admin**. On a dedicated server only admins see it. In Workbench, the local player has it.

- [ ] **B10.1 Save.** **Save game** answers **Game saved.** A second press while the first is running says a save is already running, not a second file.
- [ ] **B10.2 Time.** **+1 hour**, **+3**, **+6**, **+12** each move the clock forward by that much. The sun matches. Supplies do not get the skipped income (see B4.8).
- [ ] **B10.3 Non-admin.** A normal client does not see **Admin**. If they somehow open it, the server refuses.
- [ ] **B10.4 Game Master.** An admin (and the Workbench player) can open the editor. A normal dedicated-server client cannot.
- [ ] **B10.5 GM spawn does not poison the save.** If you spawn a prop with GM, note it, then check in Block C whether it vanished, duplicated, or threw an error. AI spawned by GM are not part of the garrison pools.

Do the setup once, fill the "before" column, restart, fill the "after" column. Pass means the two columns match, including the things that are supposed to be gone.

### C2. Extra save cases

- [ ] **C2.1 Spend more, save again, reload.** Supplies stay at the new number. The one-shot 1000 seed does not top the pile back up.
- [ ] **C2.2 Autosave.** Change one obvious thing (place a sandbag wall). Wait for the 10 minute autosave, or watch the log for `Save completed (AUTO)`. Restart from continue. The wall is there.

## D. Join in progress

The client leaves after Block C's continue is loaded, then joins again. The host stays in game and does not restart.

- [ ] **D1. Join mid-session.** Client reaches the FOB, sees the host, sees finished buildings and the map marker.
- [ ] **D2. Supplies match.** The number the client sees on the build menu or arsenal is the number the host sees.
- [ ] **D3. Their loadout.** `PT-kit-client` is there. The host's `PT-kit` is not in the client's list.
- [ ] **D4. Live fight.** Host is in contact in a town. Client drives there and sees the same groups the host is shooting, not a private copy.
- [ ] **D5. Client actions.** Client defuses or places one build. The host sees it. A later save keeps it (spot-check one item, do not repeat all of Block C).
- [ ] **D6. Rejoin twice.** Client disconnects and joins a second time. No duplicate player body, no second FOB marker, no doubled supplies.
